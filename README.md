# Inventory Management System

A console-based Python application to manage shop inventory, stock and sales. Data is saved in a JSON file.

## Features
- Add items with quantity and price
- View items with total value
- Search items by name
- Add stock and sell items (with bill amount)
- Low stock warning and report
- Total inventory value
- Delete items
- Input validation for numbers

## Technologies
- Python 3
- JSON file handling

## How to Run
```
python inventory.py
```

## Concepts Used
Functions, list comprehension, `sum()` with generator, exception handling, file handling.
